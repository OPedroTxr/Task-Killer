Política de Privacidade

Esta política descreve como o aplicativo Task Killer trata dados quando a sincronização com o Google Agenda está ativada.

Dados acessados

O Task Killer solicita somente o escopo https://www.googleapis.com/auth/calendar.app.created. Com ele, o aplicativo cria uma agenda secundária chamada "Task Killer" e gerencia os eventos dessa agenda. Ele não tem acesso a nenhuma outra agenda, evento, e-mail, contato ou arquivo da conta Google.

Como os dados são usados

O aplicativo envia ao Google Agenda as tarefas que o próprio usuário cadastrou (título, data, horário, repetição, notas, grupo e estado), apenas para que elas apareçam nessa agenda. Nenhum dado é usado para publicidade, análise ou qualquer outra finalidade.

Armazenamento e compartilhamento

Não existe servidor do Task Killer: a comunicação acontece diretamente entre o computador do usuário e as APIs do Google. O token de acesso fica salvo apenas no computador do usuário, cifrado pelo Windows (DPAPI). Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover

A sincronização pode ser desligada a qualquer momento em Configurações → Google Agenda · Alexa → Desconectar. O acesso também pode ser revogado em myaccount.google.com/permissions, e a agenda "Task Killer" pode ser apagada pelo próprio Google Agenda.
